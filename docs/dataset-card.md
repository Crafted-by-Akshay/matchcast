# MatchCast synthetic dataset card

Every match, event and scene in MatchCast is generated by our own simulator from a seed. No real event, player, club or name is in the data. Real football is used only as **aggregate statistics** to calibrate the simulator (rates, shares, one fitted curve).

## Sources used for calibration

| Source | Link | Licence | Used for |
| --- | --- | --- | --- |
| Wyscout soccer match event dataset (Pappalardo, Cintia, Rossi et al., 2019, *Scientific Data*) | https://doi.org/10.6084/m9.figshare.7770599 | CC BY 4.0 (credit given here and in the README) | The xG curve (open-play shots, 43,078) and the per-match shot, pass and duel rates. Only the fitted numbers and aggregates are stored (`data/calibration/xg.json`, `wyscout_rates.json`) |
| martj42 international football results | https://github.com/martj42/international_results | CC0 | Goals per match, share of draws, late-goal share, penalty-goal share |
| Poisson model at 2.66 goals | derived | n/a | Share of 0-0 draws |

Not used: StatsBomb open data (optional, would need credit and logo), the Kaggle European Soccer Database and FIFA rating sets (player attributes come from EA games).

## Datasets we generate

| Dataset | Where | How |
| --- | --- | --- |
| Live match events | Table `events` via the api | `apps/unified` engine, one seed per match |
| Season (28 matches) | `apps/unified/sources/enterprise-console/data/` | Earlier headless engine runs |
| Scene dataset (**Planned**: generator written, files not committed yet) | `data/scenes/v1/` (`scenes.parquet`, `manifest.json`) | `scripts/generate_scenes.py` (see below) |

## Scene dataset

Generated by `scripts/generate_scenes.py --count 240 --seed 2026`: headless full-density matches (seeds 2026 and up), cut into 30 s windows, each labelled with one of six families by fixed rules (counter-attack, high press, possession build-up, set piece, chaotic scramble, quiet spell) with the same number of scenes kept per family. One row per event.

**Label.** `danger` is 1 when the event's team takes a shot in the 10 s after the event, otherwise 0.

**Class balance, scene counts and known limits: Planned.** They are filled in from `manifest.json` when the generator's output is committed.
